# Triage Labels

Use these canonical triage states in ClickUp:

| Matt skill role | ClickUp label | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer evaluation is required |
| `needs-info` | `needs-info` | More information is required |
| `ready-for-agent` | `ready-for-agent` | Fully specified and ready for an agent |
| `ready-for-human` | `ready-for-human` | Human implementation or judgment is required |
| `wontfix` | `wontfix` | The work will not be actioned |

When a Matt skill names a triage role, use the corresponding ClickUp label. Repository-specific task statuses remain unchanged.
